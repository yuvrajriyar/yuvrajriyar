## Featured work

### [EstateFlow · Housing market analytics](https://github.com/yuvrajriyar/EstateFlow)

An end-to-end project moving Zillow home-value and rent data through Python and PostgreSQL into a three-page Power BI report. It includes a national market view, a state and metro explorer, and a guide to reading the measures and their limitations.



**Python · pandas · PostgreSQL · SQL · Power BI · Docker**

### [ProTech · Athlete performance platform](https://github.com/AggieSportsAnalytics/ProTech)

Worked with Aggie Sports Analytics on a UC Davis Football platform that brings multi-year athlete records into visual comparisons for coaching and strength staff. My contribution included team coordination, React visualisations, Supabase data workflows, and data-quality checks.

**React · Supabase · PostgreSQL · Chart.js · Recharts**

### [Dispatch Command Centre](https://yuvrajriyar.vercel.app/projects/dispatch-command-centre)

At **Soaring Roadlines Inc.**, built a Python and Streamlit dispatch application that consolidates ETAs, empty dates, and backhaul priorities across a 20-truck fleet. It cut routine fleet-tracking time by roughly half and supported more focused daily reviews.

**Python · Streamlit · SQLite · pandas**

### [NBA Injury Risk Analysis](https://github.com/yuvrajriyar/STA-141A-NBA-INJURIES)

A collaborative R project examining historical injury patterns across more than 11,000 NBA player-seasons using engineered workload, player, and injury-history features.

**R · tidyverse · randomForest · XGBoost · pROC**
